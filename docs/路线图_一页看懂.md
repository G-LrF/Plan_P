| 2.4 前端登录页 | Token 存储、请求拦截 | 「前端统一鉴权拦截」 |

**⚠️ 这一阶段有个大厂必考的坑**：很多新手只做了登录，却忘了在查询里加 `WHERE user_id = ?`，

## 五、迷茫时怎么办（给自己的规则）

### 规则 1：只看下一个动作，不看终点

```text
❌ 错误想法：「还有 7 个阶段，我什么时候才能做完」
✅ 正确想法：「这周我要把用户表建好」
```

**开发者不是靠"看到终点"坚持下去的，是靠"完成一个小目标"积累信的。**

### 规则 2：每做完一件事，必须打开浏览器看一眼

技术工作最大的问题是"成果不可见"。所以：

```text
写完接口 → 打开 /docs 点一遍
写完页面 → 打开 5173 看一眼
改完数据库 → 查一下 MySQL 里的数据
```

**看得见的进度，才有动力。**

### 规则 3：卡住超过 2 小时，就问

你卡在 MySQL 密码上花了很久，那个问题 5 分钟能解决。

**判断标准**：
- 网上搜 20 分钟没结果 → 问
- 报错看不懂 → 问
- 改了三遍还是不对 → 问

**"死磕"不是美德。真实开发中，及时求助才是专业。**

### 规则 4：一次只学一个新东西

```text
❌ 同时学：SQLAlchemy + Alembic + JWT + pytest
✅ 先学 SQLAlchemy，用熟了再加 Alembic
```

**同时引入两个新变量，出问题时无法判断是哪个引起的。**

### 规则 5：记下每个坑

你已经踩过不少坑（IDE 自动改导入、中文乱码、密码记错、`.gitignore` 规则顺序）。
**这些记录比代码更值钱** —— 它们是你未来的"经验值"。
